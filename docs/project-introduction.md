# 店小智：项目介绍与使用说明

版本：v0.6.2 新生杯答辩测试版｜更新日期：2026 年 10 月 25 日

## 项目简介（可直接转发）

店小智是一款面向校园周边便利店、小卖部等小型门店的轻量经营工具。项目支持商品与库存管理、采购销售录入、CSV / Excel 导入、库存预警、简化财务三表、经营问答，以及建议执行和复盘，帮助店主将日常记录转化为可查看、可核对的经营信息。系统支持电脑和手机网页访问，账本保存在本机，可导出备份和恢复，并提供可选的 GLM-4-Flash 辅助问答。当前为新生杯答辩与小范围测试版本，演示数据与真实门店记录相互隔离。

## 如何使用

1. **打开网页**：访问下方在线试用地址，使用团队提供的邀请码进入；邀请码单独领取。
2. **先体验演示**：点击“查看演示”，浏览已有的商品、流水、报表和经营建议。
3. **建立自己的门店**：进入“我的门店”，填写店名，建立商品档案，再录入采购、销售和费用。
4. **查看经营结果**：仪表盘、库存和三张报表随录入更新；经营问答默认在本地查询账本，选择模型问答时需联网并确认发送范围。
5. **保存与安装**：在“门店与数据”导出 JSON 备份；新设备使用相同模式恢复。支持的手机浏览器可通过菜单添加到桌面。

账本保存在当前设备和浏览器，不自动云同步。首次联网准备好离线资源后，可继续使用本机记录；离线不支持模型调用。当前只覆盖单门店整数计件商品及简化经营账，真实经营效果仍需门店试用核实。

## 电脑本机运行

取得源码并安装 Node.js 22 或更新版本后，在项目目录执行：

```sh
cd app
npm start
```

浏览器打开 http://127.0.0.1:19393 。Windows 也可双击 `app/start.cmd`。默认本机运行不需要配置模型密钥，可使用记账、报表和本地问答。
