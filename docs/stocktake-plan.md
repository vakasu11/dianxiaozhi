# v0.6 库存盘点

目标：店主核对实物与账面库存时，能够先看清差异，再记录原因并确认入账。

沿用现有工作台的纸白 #FFFFFF、灰底 #F6F7F9、正文 #1F2937、次要文字 #64748B、业务绿 #0F766E、边线 #D8DEE6；系统中文字体，数量及金额使用等宽数字。左对齐的单商品盘点表单与差异核对区域，上方选择商品，下方依次填写数量、原因、确认；手机按同样顺序排列。历史表呈现原账面、实盘、差异和原因，不增加装饰卡片或宣传文案。

方案复核：此页以“账面 → 实盘 → 差异”的业务顺序建立层级，突出确认前的损益影响，不套用普通仪表盘指标布局。

约定：

- 只支持整数计件、单商品逐笔盘点，遵守现有日期顺序。
- 盘亏按当时移动加权成本计入库存损失；盘盈按当时平均成本，零库存时按保存的参考进价估值，单独计入盘盈收益。
- 不生成营业收入、销售数量或现金流水。不修改原采购或销售。
- 保存账面数量、成本和估值依据，可复核；预览后有其他修改时阻止提交。
- 数据结构升为 v4，兼容旧 v1/v2/v3 数据；本地保存、备份和离线缓存一同升级。
- 导入暂不支持盘点，必须在盘点页预览确认。这里只提供简化经营核对，无法替代正式账务审批。
