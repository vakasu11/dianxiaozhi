## 实际验证

自动测试共 48 项通过，运行 `cd app && npm test`。包括原库存、三表、导入、复盘、服务接口测试，以及订单合并和冲突、7/14/30天条件、活动成本拦截、费用估算、旧数据迁移、匿名报告和离线缓存边界。

浏览器验收使用独立测试端口，不改默认 19393 的真实录入记录：

- 演示初始14单 / 21条销售明细，营业收入463.50元，客单33.11元；同日新增带编号销售后为15单，问答显示31.03元，与明细一致。
- 候选登记→建档，库存保持0；示例牛奶7天观察显示销量49、销售171.50元、毛利73.50元；14/30天未满不显示结果。
- 活动价0.50元低于1元成本时阻止保存；改1.80元可保存，登记执行不生成虚构交易。
- 登记45分钟、8元服务投入，报告与原有30分钟示例合计；费率与反馈状态刷新后保留。
- 匿名图文报告实际触发浏览器下载，包含收入图表和口径说明。
- 手机尺寸预览：实际CSS宽375，页面 scrollWidth 375，无整页横向溢出；表格在容器内横向查看。菜单可展开与关闭。
- 应用更新提示→确认更新，27条测试业务及反馈保持。停止19397测试服务后重新载入，显示“离线 · 使用本机记录”；反馈从处理中改为已解决，刷新仍保留。
- 本地模型协议替身：成功问答、失败回退、文案润色待核对保存，最终3次调用（2成功、1失败）；每次成功返回1000输入/500输出token，按输入1元、输出4元/百万token估算共0.0060元，失败费用待核实。保存润色文案没有覆盖调用历史。

## 仍需现场完成

真实供应商在线响应、真实门店试销、付费与经营效果均尚未验证。手机/系统级PWA安装未实测；已验证清单、图标、安装说明、离线和更新流程。当前是本机或静态HTTPS可运行的单门店应用；没有公网登录、多店隔离和云端同步。

原P0中的退货、盘点、箱件换算、批次临期和完整会计账仍不包含在本次P1补全范围。退款等复杂业务暂不要按普通销售反向录入。P2路线见原任务清单。

PWA安装要求及浏览器差异参考 [MDN](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)。离线能力由本应用Service Worker实现，业务仍保存在浏览器本地。
