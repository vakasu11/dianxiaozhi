# 店小智：28 天答辩测试部署

适用版本 v0.6.2。目标是腾讯云 CloudBase 国内环境、团队及少量试点使用、尽量 0 元。2026-10-25 已在用户的上海体验环境部署，公网接口和真实 GLM-4-Flash 调用已验证；用户已确认公网工作台显示。浏览器全流程、实际账本迁移和真实手机验收仍需完成，详见 [验收记录](cloud-demo-validation.md)。密钥由用户在平台配置，不随源码保存。

## 1. 账号与免费环境

进入 [CloudBase 控制台](https://console.cloud.tencent.com/tcb)，完成个人账号注册、实名及平台要求的服务开通，在创建环境页面确认免费资格、有效期和剩余额度。不要在“轻量应用服务器 / CVM 免费试用”活动页选购服务器。

[CloudBase 定价页](https://www.cloudbase.net/pricing)当前列出免费套餐及 3000 资源点/月；个人账号是否可选免费套餐或新用户个人版免费期，以控制台实际展示为准。额度耗尽或到期的行为也须在控制台核实。不要为本次测试开启付费升级、自动续费或额外付费资源。非商业用途不代表平台一定免收费。

把环境 ID 和地域提供给开发者即可；不要发送账号密码、云访问密钥或智谱 API Key。

## 2. 部署包与入口

使用 `dianxiaozhi-cloudbase-v0.6.2.zip`；ZIP 内的 `scf_bootstrap` 位于根目录，使用 LF 换行并带 Unix 755 权限。无需安装 npm 依赖。

在 CloudBase 创建 **HTTP / Web 云函数**，运行环境选择 **Node.js 22.21**（须与启动文件 `/var/lang/node22/bin/node` 对应），上传 ZIP。应用监听 `0.0.0.0:9000`。函数超时设 60 秒，最小实例 0，最大实例建议 1（若当前套餐控制台不支持此设置，须按实际实例限制核实，不能假定单实例）。不挂载数据库、对象存储或持久化磁盘；不启用会记录请求正文的自定义日志。初次部署缺少环境变量时会拒绝启动，先填写下节配置。

通过环境的 HTTP 访问服务配置 **根路径 `/` 转发到此 HTTP 云函数**，保留原始路径。网页 `/`、`/app.mjs`、`/api/status`、`/api/login`、`/api/chat` 必须在同一 HTTPS 域名下访问；不要只映射 `/函数名`，不要把 API 单独放在另一个域名。若控制台只支持带前缀路径，请暂停并提供界面，由开发者适配后重打包。

使用平台生成的 HTTPS 测试域名作为 `PUBLIC_ORIGIN`，不得带路径、查询或片段，例如 `https://你的环境.service.tcloudbase.com`。实际域名以控制台为准，示例不能直接填。当前服务严格校验 Host 与 Origin；若网关改写 Host，需先依据真实请求元数据适配可信网关，不能删除所有校验来绕过 403。

若创建函数时尚未得到测试域名，可暂用保留的占位地址 `https://pending.invalid` 完成初始化，并同时配置随机邀请码哈希、会话密钥和截止时间。此时 `/healthz` 可检查进程是否启动，实际域名的网页与 API 会因 Host 不匹配而被拒绝；创建 HTTP 网关路由并取得真实域名后，必须更新 `PUBLIC_ORIGIN` 并部署配置，才能开始网页访问验收。占位地址不是可访问的网站。首次导入的初始化配置不含智谱 Key，需由账号持有人在云端单独添加 `GLM_API_KEY`。界面的“API Key 设置”是 CloudBase 资源授权开关，本项目不调用其数据库 SDK，保持关闭。

平台默认域名仅用于小范围测试，浏览器可能先显示访问确认页；部分默认域名请求存在附件下载限制。必须完成第 5 节检查后才能分享。若模块或 Service Worker 被下载/拦截，不能当作部署成功，应改用平台支持的网页托管入口或具备域名的 HTTPS 方案，再配置同域 API。自有域名及备案不是本次已经具备的条件。

参考：[HTTP 云函数快速开始](https://docs.cloudbase.net/cloud-function/quickstart/httpfunc/nodejs)、[运行时](https://docs.cloudbase.net/cloud-function/runtime-support)、[启动文件](https://docs.cloudbase.net/cloud-function/develop/scf-bootstrap)、[默认域名规则](https://docs.cloudbase.net/service/alias)。

## 3. 云函数环境变量

在云函数配置页填写，不能写进前端、GitHub 或发到聊天里：

| 变量 | 填写方式 |
| --- | --- |
| `APP_MODE` | `cloudbase` |
| `PORT` | `9000` |
| `PUBLIC_ORIGIN` | 实际测试 HTTPS 根地址 |
| `GLM_API_KEY` | 新的智谱 API Key，由账号持有人直接填 |
| `INVITE_HASHES` | 原始邀请码的 SHA256，小写十六进制；多个以英文逗号分隔 |
| `SESSION_SECRET` | 随机生成，至少 32 字符 |
| `DEMO_END_AT` | ISO 8601 截止时间；建议开通日起 28 天，不能超过启动时起 31 天 |

本地在 app 目录手动运行 `node scripts/create-invites.mjs 5` 可生成 5 个独立邀请码、哈希、随机会话密钥及 28 天截止时间。输出属于私密配置，私下保存；不要提交仓库。将每个原始邀请码分别给一名试用者，云端只填写哈希。不要使用短口令或相同口令替代随机码。

模型固定为 `glm-4-flash-250414`，使用智谱官方 Chat Completions 接口；不会自动切换收费模型、联网搜索或调用工具。[官方定价](https://docs.bigmodel.cn/cn/guide/start/pricing)目前标注该型号输入输出免费；真实模型权限、并发及额度仍以账号和请求结果为准。未配置 Key 时可以使用本地查数，不会伪造模型回答。

## 4. 数据与访问边界

- 门店、商品、流水、聊天、试销与反馈保存在当前浏览器。测试后端不写账本或对话到云数据库/文件。它仍会接收经同意发送的本次问题和汇总；智谱与云平台按各自服务规则处理，不能声称数据从未离开手机。
- 默认使用本地规则。模型勾选框每次渲染恢复未选中；勾选后发送本次问题、统计期间、财务与订单汇总、商品名称及库存，每类明细最多 100 条。服务端再次按白名单裁剪；不转发整本流水、订单号、聊天记录、门店名称、反馈原文。问题和活动草稿属于自由文本，请勿自行填入隐私信息。活动润色只发送本条活动信息。
- 邀请会话使用 HttpOnly / Secure / SameSite Cookie，有效期最多 8 小时且不超过测试截止。退出删除当前浏览器 Cookie；若需撤销已复制的会话，移除对应邀请码哈希并重新部署，或轮换会话密钥使全部会话失效。
- 在线接口每邀请码每分钟 5 次、每 24 小时 30 次，整个进程每 24 小时 100 次，最多同时 2 次、同邀请码同时 1 次。按开始请求计数，包括上游失败；时间窗口从首次请求算起，并非自然日。限频仅在单进程内存生效，重启、冷启动和扩容会重置，不是跨实例限额或账单硬上限。
- 请求最多 80 KB；响应最多 1200 token、25 秒上游超时。失败或超限会回退本地问答。模型用量在本机记录，未核实费率不按零费用处理。
- 静态网页资源可公开获取，邀请码保护在线入口及 API，不能加密浏览器账本。之前验证过的浏览器断网后可继续本机操作；测试结束也不删除已有记录。退出在线试用不清除本机账本，共用设备需单独浏览器账户。

## 5. 上线前必须实际验收

1. 打开测试域名，处理平台提示页后，HTML、`.mjs`、图标和 manifest 正常显示，不能弹出源码下载。`/healthz` 返回 `ok:true`；错误 Host 不作为绕过方法。
2. 无痕窗口进入显示邀请码；错误码被拒绝，正确码进入。未登录直接 POST `/api/chat` 返回 401；其他 Origin 返回 403；篡改 Cookie 被拒绝。
3. 先只用**模拟演示数据**勾选模型提问一次，确认智谱返回实际文本，后台模型名称正确、Key 未出现在网页源码/网络响应/仓库中。再取消勾选，确认本地问答不发 `/api/chat`。
4. 手机浏览器录入测试商品和销售，关闭重开后仍在；安装与离线资源须在真实设备验证。飞行模式能查账并导出备份，不能请求模型。
5. 导出本机备份再更新网页，核对数字与此前一致。浏览器、域名或协议变化都会形成不同的数据空间，不能当成数据丢失或自动同步。
6. 核对免费期、额度和函数访问统计；不要把自动化测试或模拟接口当作真实模型调用/商户效果证明。

## 6. 答辩结束

提前导出各设备备份；截止时间后服务端拒绝新登录与模型请求。团队随后在控制台删除 HTTP 路由/云函数或停用测试环境并核对资源账单，撤销本次测试使用的智谱 Key。邀请码截止不会代替关闭云资源。代码不内置自动删除云环境的任务。

## 7. 本地开发与重新打包

Node.js 22 及以上，无第三方运行依赖。`app/.env.example` 是本地配置示例，Node 不会自动读取 `.env`，需用 `node --env-file=.env server.mjs`。本机默认只监听 127.0.0.1，云模式由启动文件开启。

在 app 目录执行 `node --test tests/*.test.mjs`，再执行 `node scripts/build-cloudbase.mjs`。输出目录不能已有文件；包内 MANIFEST.json 可校验每个文件，ZIP 旁有 SHA256。只包含 public 资源、服务端、启动脚本、示例配置及此文档，不含真实 Key、邀请码、门店备份或本地验收记录。
