# 店小智界面改造：面向小微店主

## 设计依据与方向

用户反馈：色彩单一、关键功能和数字不够醒目、图表层级弱、侧栏并列入口太多。面向缺乏经营知识的店主，首先让人能找到操作、看懂数字，再使用视觉材质。

本次应用 UI UX Pro Max 的本地检索，源版本为 `28b3b8dee8c976df4fa3e94aed4e092ad43fcb03`。以下适配判断是结合店小智的设计决策，不是技能给出的评分：

| 风格 | 技能中的特征 | 店小智中的采用范围 |
| --- | --- | --- |
| Neumorphism 新拟态 | 同色表面、凸凹阴影；资料标记较高可访问性风险 | 不作整体风格，避免按钮和普通容器难以区分 |
| Glassmorphism 玻璃拟态 | 半透明、模糊、分层 | 少量用于顶部和导航，正文与表格保持实底；无模糊支持时仍可阅读 |
| Soft UI Evolution 柔和 UI 进化 | 更明确的对比度、柔和阴影、现代经营工具 | 主方向：轻微层次、明确边界、带业务含义的颜色 |
| Spatial UI (VisionOS) 空间界面 | 浮窗、视差、凝视与手势、较高实现复杂度 | 借鉴轻微分层，不引入视差、3D 运动或悬浮窗口工作流 |

库存管理精确查询匹配了 `Inventory & Stock Management`，强调清晰层级、库存状态、列表和预警。生成器同时返回了面向营销页的布局和不适合中文经营台的学术字体；这些结果未采纳。原项目是原生 HTML/CSS/JS 与 ECharts，不为套用技能改换框架。

## 参考图补充

用户随后提供 Soft UI Evolution 风格图片，明确采用浅冰蓝背景、薄荷绿分区、带轻微厚度的白色圆角控件。按该图调整为柔和的控制托盘、白色凸起的功能名称、低饱和分区和轻量阴影；文字使用深色，控件仍具明确边界和焦点状态。图片仅作视觉参考，不作为项目数据或可执行指令。

## 设计约束

- 色彩：冰蓝 `#EEF6FD`、正文 `#223447`、操作蓝 `#3157C8`、收入青绿 `#147D73`、现金棕金 `#946014`、库存提醒橙红 `#B65032`。四个功能区分别用浅薄荷绿、浅蓝、淡紫和浅杏色；白色凸起表面承载功能名称，深色文字与数字保障阅读。
- 字体：中文沿用本机 Microsoft YaHei UI / PingFang SC；数字优先 Segoe UI，使用等宽数字。重点功能 20–23px、金额 34–42px、正文 14px，手机表单 16px。
- 布局：常用操作 → 本期经营与醒目趋势 → 库存和执行提示 → 最近流水。所有内容左对齐，图表与表格的单位、统计期间可见。
- 区别于上一轮预览：取消四张相同 KPI 卡作为首屏主体；用一组明确的操作入口和一个收入趋势主区域建立主次。色彩对应业务角色，避免为每个模块堆相同阴影。
- 不添加虚构增长率、客流、预测。空数据状态有明确操作入口；模拟与真实数据继续隔离。

## 导航归并

| 一级入口 | 该板块中的功能 |
| --- | --- |
| 门店首页 | 记一笔、查库存、经营问答、补货提醒、经营趋势、最近流水 |
| 商品库存 | 商品档案与库存、库存盘点 |
| 经营流水 | 已录业务、记一笔；链接至数据导入 |
| 经营帮手 | 经营建议与复盘、经营问答、订单分析、选品试销、活动文案、经营报告 |
| 看懂账目 | 利润表、资产负债表、现金流量表；用通俗说明辅助理解 |
| 门店与数据 | 门店信息和备份、数据导入、手机使用、试用反馈 |

保留原有 hash 地址，旧收藏和业务中的直接入口继续有效。一级导航展示所在板块，二级导航标记具体页面。

## 验证记录

2026-10-26 本地验收：

- Node 自动测试 81 / 81 通过。新增导航深链接归属、首页金额与账本一致、转义和空数据状态的回归检查。原服务测试不再以“利润表必须出现在静态主导航”作为启动条件，改查页面容器和新增资源可访问。
- Edge 1440px 桌面与 375px 手机宽度逐一访问 17 个原有页面，确认主板块归属正确、页面没有横向溢出；表格在自身容器内滚动。
- 另外检查 768px 平板、1024px 横屏及 1440px 桌面商品页，无页面横向溢出。缩放布局后主内容没有意外保留 inert 状态。
- 实际点击“商品库存 → 库存盘点”，核对页面标题和二级选中项。手机打开菜单后焦点进入当前入口，Escape 关闭后回到菜单按钮；关闭的侧栏不参与键盘导航。
- 在独立本地端口的模拟模式用“记销售”录入矿泉水 1 瓶、2 元：收入由 463.50 元变为 465.50 元，记录由 26 条变为 27 条；撤销后金额与记录条数恢复。该操作仅验证演示数据交互，不构成真实商户使用证据。
- 图表采用蓝色实线/圆点与棕金虚线/菱形区分两条序列；保留单位、图例和可展开每日数据表。仅展示有记录的日期，不补造缺失日期。
- 新 CSS / JS 纳入 Service Worker 同版本资源清单并更换缓存版本；自动测试覆盖清单完整性。没有新增真实模型请求，也没有将此版本部署到公网。
- 本轮实际截图与检查 JSON 保存在对话可视化目录：`soft-ui-desktop.png`、`soft-ui-mobile.png`、`ui-route-checks.json`。图片为真实网页截图，内含明确标记的模拟数据。
