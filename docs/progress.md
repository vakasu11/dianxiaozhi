## 下一轮优先级

1. 顾客退款与采购退货：关联原流水、限制可退数量、正确冲回成本和款项，避免用负销售代替。
2. 商户试用：先找 1 家店、少量整数计件商品，连续核对录入耗时、库存差异、备份恢复和建议执行。
3. 依据试用结果决定批量盘点、箱件转换、临期管理与更大容量本地存储的顺序。
4. 完成公网操作、原本机账本迁移和真实手机安装 / 离线验收。

竞赛材料中的调查样本、店主意愿、试用门店、节省时间、付费或营收提升，均须另行收集真实证据；软件演示不能代替这些结果。
