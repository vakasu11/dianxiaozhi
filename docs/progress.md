# 开发进度（2026-10-20）

当前版本 v0.6.1：已形成可本机运行、可打包为静态站点的单门店手机网页 / PWA，处于小规模试用准备阶段。本地电脑人工验收已完成，修复了问答条数与期间显示；逐项结果和缺项见 [验收报告](pc-acceptance.md)。

| 模块 | 当前已实现 | 尚需补充或验证 |
| --- | --- | --- |
| 商品与业务 | 商品档案、初始投入、采购、销售、报损、费用、赊账收付、业主资金、顺序撤销 | 顾客退款、采购退货、称重小数、箱件转换 |
| 库存核对 | 单商品盘点预览、确认、账面快照、原因、盘盈盘亏、流水撤销 | 批量盘点、批次及临期管理 |
| 财务 | 与同一账本联动的简化利润表、资产负债表、现金流量表，CSV / 打印 | 税费、折旧、完整会计账、参赛用预测三表 |
| 导入 | CSV / Excel 本地解析、映射、整批校验、去重、冲突及批次撤销 | 盘点通过专用页面确认，暂不支持导入 |
| 经营分析 | 有编号订单、商品排名、时段、组合、完整期间后的补货与低销量观察 | 真实经营效果、跨平台自动获取业务数据 |
| 执行闭环 | 采纳 / 拒绝、实际执行、关联补货、持续复盘 | 真实门店的连续使用证据 |
| 试销与运营 | 候选来源、试销 7/14/30 天观察、活动草稿、执行登记、反馈跟进 | 实际营销转化与可证明的收益 |
| 报告与问答 | 匿名图文报告、服务工时 / 费用、本地规则问答 | 外部大模型按用户要求延期，当前无在线模型调用 |
| 手机与本地数据 | 响应式布局、离线缓存、安装指引、JSON 备份恢复、冲突保护、路径隔离 | 真机系统安装、长期大数据量、跨设备同步（当前不提供） |
| 发布 | 本地启动、静态构建、部署包、私有源码仓库 | 公网 Pages 尚未上线；上次启用返回当前方案不支持该私有仓库 |

## 下一轮优先级

1. 顾客退款与采购退货：关联原流水、限制可退数量、正确冲回成本和款项，避免用负销售代替。
2. 商户试用：先找 1 家店、少量整数计件商品，连续核对录入耗时、库存差异、备份恢复和建议执行。
3. 依据试用结果决定批量盘点、箱件转换、临期管理与更大容量本地存储的顺序。
4. 本地流程稳定后，再处理手机 HTTPS 发布地址及可选大模型。

竞赛材料中的调查样本、店主意愿、试用门店、节省时间、付费或营收提升，均须另行收集真实证据；软件演示不能代替这些结果。
