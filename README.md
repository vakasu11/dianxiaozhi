# 店小智 Dianxiaozhi

店小智是一款面向校园周边便利店、小卖部等小型门店的轻量经营工具。它将商品、库存和经营流水连接起来，帮助店主查看经营状况、发现库存问题，并记录经营建议的执行与复盘。

当前版本为 **v0.6.2 新生杯答辩测试版**，支持电脑和手机网页访问。账本保存在当前设备的浏览器，支持 JSON 备份与恢复；默认使用本地数据问答，可在联网、服务配置及邀请码验证通过后选择 GLM-4-Flash 辅助问答，每次发送前单独确认。

## 主要功能

- 商品档案、采购与销售录入、库存报损和逐商品盘点。
- CSV / Excel 导入、字段映射、整批校验、去重与导入记录撤销。
- 根据同一套流水计算简化利润表、资产负债表和现金流量表。
- 库存预警、补货与低销量观察、建议依据、实际执行与复盘记录。
- 订单与商品分析、试销观察、活动草稿、经营报告和本地 / 可选模型问答。
- 手机适配、PWA 安装入口、离线资源、本机保存及备份恢复。

## 如何使用

1. 打开在线试用地址，输入团队提供的邀请码；首次体验可点击“查看演示”。演示与真实门店的记录相互隔离。
2. 正式试录时进入“我的门店”，在“门店与数据”填写店名，在“商品与库存”建立商品。
3. 点击“记一笔”，录入采购、销售、费用等业务，库存、仪表盘和三张报表会随记录更新。
4. 在“经营建议与复盘”查看问题与依据；在“经营问答”查询利润、库存、应收应付等。使用外部模型前核对本次发送范围。
5. 在“门店与数据”定期导出完整 JSON 备份；换设备或浏览器时，在相同数据模式下恢复备份。
6. 支持的手机浏览器可通过菜单添加到桌面。首次联网准备好离线资源后，可继续使用本机记录；离线时无法调用模型。

当前版本适用于单门店、整数计件商品的小范围测试。税费、折旧、退款、批次临期和箱件自动换算尚未覆盖；三张表是简化经营报表。记录不会自动跨设备同步。

## 本地运行

需要 Node.js 22 或更新版本，无需安装 npm 运行依赖。

```sh
cd app
npm start
```

访问 `http://127.0.0.1:19393`。Windows 也可运行 `app/start.cmd`。

默认进入空白的“我的门店”，可主动切换到明确标记的演示数据。两种模式独立保存，不会自动同步到云端。模型 Key 只在服务端环境变量中配置，前端不接收密钥。
