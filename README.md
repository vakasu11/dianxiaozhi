# 店小智 Dianxiaozhi

为学校周边便利店、小卖部等小型门店设计的经营工作台。通过商品和业务记录连接库存、财务、经营建议及执行复盘。

当前版本 **v0.4**：第二阶段加入订单与毛利分析、选品试销、活动草稿、匿名图文经营报告、模型与服务成本、反馈跟踪、PWA离线及应用更新。界面调整为日常门店工作台。

## 本地运行

需要 Node.js 22 或更新版本，无需安装 npm 运行依赖。

```sh
cd app
npm start
```

访问 `http://127.0.0.1:19393`。Windows 也可运行 `app/start.cmd`。

默认提供明确标记的演示数据。“我的门店”使用独立的本地存储，不会自动同步到云端。密钥只通过服务器环境配置。
